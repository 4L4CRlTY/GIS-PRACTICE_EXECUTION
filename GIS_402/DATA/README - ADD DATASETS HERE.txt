GIS 402 - ADD DATASETS HERE

Blanko kini by design. Ayaw kabalaka kung walay actual map/data file pagkahuman sa download.

1. Ablihi ang main GIS-PRACTICE repository:
   https://github.com/4L4CRlTY/GIS-PRACTICE

2. Basaha ang:
   GIS_402\GUIDE TUTORIAL\DATASET SOURCE AND SETUP GUIDE - BISAYA.md

3. Sundon ang matching Exercise 03-16 guide.

4. I-download o i-copy ang dataset gikan sa source nga giingon sa guide.

5. I-extract ang ZIP/7z ug ibutang ang TANANG companion files sa matching exercise folder.

Shapefile example:
Regions.shp = map geometry
Regions.dbf = attribute table
Regions.shx = geometry index
Regions.prj = coordinate system
Regions.cpg = text encoding

Kinahanglan mag-uban kining mga files. Ayaw i-copy ang .shp nga siya ra.
