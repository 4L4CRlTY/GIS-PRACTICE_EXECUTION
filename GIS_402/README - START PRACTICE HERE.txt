GIS 402 - EXERCISE 02 FOLDER WORKSPACE

PURPOSE
Kini nga folder mao ang ready-made Exercise 02 structure. Blanko ang DATA ug OUTPUT folders. Ikaw ang mokuha sa datasets pinaagi sa main guide ug maghimo sa Exercises 03-16.

QGIS NGA GAMITON
QGIS Desktop 2.14.3 Essen

UNSAON PAGSUGOD
1. Ablihi ang main guide: https://github.com/4L4CRlTY/GIS-PRACTICE
2. Basaha ang Dataset Source and Setup Guide sa main repository.
3. Sugdi ang Exercise 03.
4. Kuhaa ang dataset gikan sa source nga giingon sa guide.
5. Ibutang ang complete dataset sa matching empty DATA folder.
6. Ablihi ang QGIS Desktop 2.14.3 Essen.
7. Buhata ang exercise gikan sa sinugdanan.
8. I-save ang imong result sa matching Exercise folder sulod sa OUTPUT.

IMPORTANTE
- Ayaw pagkuha og completed output gikan sa original GIS_402 folder samtang nag-practice.
- Ang main GIS-PRACTICE repository mao ang guide/reference copy.
- Kining GIS_402 mao ang imong working copy.
- Ayaw i-edit diretso ang input DATA. Kung kinahanglan og editable copy, i-save una kini ngadto sa matching OUTPUT folder.
- Kanunay i-check ang Exercise number sa DATA ug OUTPUT folder names.

OUTPUT LOCATIONS
- QGIS project (.qgs): OUTPUT\PROJECT\Exercise XX - ...
- Vector/shapefile: OUTPUT\VECTORS\Exercise XX - ...
- Raster (.tif): OUTPUT\RASTERS\Exercise XX - ...
- CSV/table: OUTPUT\TABLES\Exercise XX - ...
- Final map/layout image: OUTPUT\GRAPHICS\Exercise XX - ...

SUCCESS CHECK
Human sa exercise, pwede nimo i-compare ang imong result sa expected output screenshot sa main repository picture tutorial. Ayaw kopyaha ang completed file; gamita lamang ang screenshot isip visual reference.
