BLANK PRACTICE OUTPUT

Walay completed exercise outputs niini nga workspace.

I-save ang imong kaugalingong resulta sa sakto nga category ug Exercise folder:

- GRAPHICS = final map/layout images
- PROJECT = QGIS .qgs project files
- RASTERS = georeferenced o generated .tif files
- TABLES = CSV ug other tables
- VECTORS = shapefiles ug related vector files

Example:
Exercise 05 project -> PROJECT\Exercise 05 - Creating a New Dataset
Exercise 05 shapefile -> VECTORS\Exercise 05 - Sogod_Bndry

Ayaw kalimot: ang usa ka shapefile dili .shp lamang. Kinahanglan magkauban ang .shp, .shx, .dbf, ug .prj files.
